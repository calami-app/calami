## 为什么选择 Calami？

大多数 Markdown 应用专注于写作。Calami 为**阅读和写作**而生 — 一个应用即可撰写文章、研读文档、批注 PDF、演示幻灯片，无需离开你的工作空间。

轻量、跨平台，文件始终留在你的设备上。

## 核心功能

### 📖 沉浸式阅读

将任何 Markdown 文件变为干净的、类似书籍的阅读体验。选中单词即可获得即时翻译，用彩色标注高亮段落，或让应用为你朗读。

<p align="center">
<img src="./assets/reading.png" width="720" alt="沉浸式阅读" />
</p>

### ✍️ AI 辅助写作

随时在富文本模式和源码模式之间切换。AI 助手常驻侧边栏 — 让它帮你总结、续写、润色或翻译。支持自带 API Key（OpenAI、Claude、Gemini 或本地模型均可）。

<p align="center">
<img src="./assets/writing.png" width="720" alt="AI 辅助写作" />
</p>

### 🎬 演示文稿

一键将任何 Markdown 文件变为幻灯片。直接从笔记中展示你的想法 — 无需切换到 PowerPoint 或 Google Slides。

<p align="center">
<img src="./assets/presenting.png" width="720" alt="演示文稿" />
</p>

### 🎨 个性定制

从内置主题和皮肤中选择，或用自然语言描述一种风格，让 AI 为你生成自定义皮肤。调整字体、间距和布局，打造你的专属风格。

<p align="center">
<img src="./assets/theming.png" width="720" alt="个性定制" />
</p>

### 📤 随处导出

一键导出为 PDF、HTML、Word、PNG、EPUB 或思维导图。直接发布到图床服务。

<p align="center">
<img src="./assets/export.png" width="720" alt="随处导出" />

## 常见问题

<details>
<summary><strong>Calami 和 Typora / Obsidian / Bear 有什么不同？</strong></summary>

Calami 将阅读视为一等体验 — 沉浸模式、即时翻译、生词本、仿生阅读、文字转语音全部内置。

</details>

<details>
<summary><strong>能离线使用吗？</strong></summary>

可以。除了云端 AI，所有功能都可离线使用。如果你使用 Ollama 等本地模型，AI 也能在无网络时工作。

</details>

<details>
<summary><strong>我的数据安全吗？</strong></summary>

你的文件以标准 Markdown 格式存储在本地。无云同步，无需注册账号。AI 请求直接发送到你选择的服务商 — Calami 永远不会看到你的内容。

</details>
