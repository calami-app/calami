## 왜 Calami인가요?

대부분의 Markdown 앱은 쓰기에 집중합니다. Calami는 **읽기와 쓰기 모두**를 위해 만들어졌습니다 — 기사 작성, 문서 학습, PDF 주석, 슬라이드 발표를 작업 공간을 떠나지 않고 모두 할 수 있는 하나의 앱입니다.

가볍고, 크로스 플랫폼이며, 파일이 절대 기기를 떠나지 않습니다.

## 핵심 기능

### 📖 몰입형 읽기

모든 Markdown 파일을 깔끔한 책과 같은 읽기 경험으로 바꿉니다. 단어를 선택하면 즉시 번역을 받고, 색상 코드 주석으로 구절을 강조하거나, 앱이 소리 내어 읽어줍니다.

<p align="center">
<img src="./assets/reading.png" width="720" alt="몰입형 읽기" />
</p>

### ✍️ AI와 함께 쓰기

리치 텍스트 모드와 소스 모드를 언제든 전환할 수 있습니다. AI 어시스턴트가 사이드바에 상주합니다 — 요약, 이어 쓰기, 문장 다듬기, 번역을 요청하세요. 자신의 API 키를 가져오세요 (OpenAI, Claude, Gemini 또는 로컬 모델 모두 작동).

<p align="center">
<img src="./assets/writing.png" width="720" alt="AI와 함께 쓰기" />
</p>

### 🎬 프레젠테이션

클릭 한 번으로 모든 Markdown 파일을 슬라이드쇼로 변환합니다. 노트에서 직접 아이디어를 발표하세요 — PowerPoint나 Google Slides로 전환할 필요가 없습니다.

<p align="center">
<img src="./assets/presenting.png" width="720" alt="프레젠테이션" />
</p>

### 🎨 나만의 스타일로

내장 테마와 스킨에서 선택하거나, 일상 언어로 스타일을 설명하면 AI가 맞춤 스킨을 생성합니다. 글꼴, 간격, 레이아웃을 취향에 맞게 조정하세요.

<p align="center">
<img src="./assets/theming.png" width="720" alt="커스터마이징" />

### 📤 어디로든 내보내기

클릭 한 번으로 PDF, HTML, Word, PNG, EPUB 또는 마인드맵으로 내보내기. 이미지 호스팅 서비스에 직접 게시할 수 있습니다.

## FAQ

<details>
<summary><strong>Calami는 Typora / Obsidian / Bear와 어떻게 다른가요?</strong></summary>

Calami는 읽기를 최고 수준의 경험으로 다룹니다 — 몰입 모드, 즉시 번역, 단어장, 바이오닉 리딩, 텍스트 음성 변환이 모두 내장되어 있습니다.

</details>

<details>
<summary><strong>오프라인에서 작동하나요?</strong></summary>

네. 클라우드 기반 AI를 제외한 모든 것이 오프라인에서 작동합니다. Ollama와 같은 로컬 모델을 사용하면 AI도 인터넷 없이 작동합니다.

</details>

<details>
<summary><strong>내 데이터는 안전한가요?</strong></summary>

파일은 표준 Markdown으로 기기에 저장됩니다. 클라우드 동기화 없음, 계정 불필요. AI 요청은 선택한 제공업체로 직접 전송됩니다 — Calami는 절대 콘텐츠를 보지 않습니다.

</details>
