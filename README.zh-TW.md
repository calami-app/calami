## 為什麼選擇 Calami？

大多數 Markdown 應用專注於寫作。Calami 為**閱讀和寫作**而生 — 一個應用即可撰寫文章、研讀文件、批註 PDF、演示投影片，無需離開你的工作空間。

輕量、跨平台，檔案始終留在你的裝置上。

## 核心功能

### 📖 沉浸式閱讀

將任何 Markdown 檔案變為乾淨的、類似書籍的閱讀體驗。選取單字即可獲得即時翻譯，用彩色標註醒目段落，或讓應用為你朗讀。

<p align="center">
<img src="./assets/reading.png" width="720" alt="沉浸式閱讀" />
</p>

### ✍️ AI 輔助寫作

隨時在富文本模式和原始碼模式之間切換。AI 助手常駐側邊欄 — 讓它幫你摘要、續寫、潤飾或翻譯。支援自帶 API Key（OpenAI、Claude、Gemini 或本地模型均可）。

<p align="center">
<img src="./assets/writing.png" width="720" alt="AI 輔助寫作" />
</p>

### 🎬 簡報

一鍵將任何 Markdown 檔案變為投影片。直接從筆記中展示你的想法 — 無需切換到 PowerPoint 或 Google Slides。

<p align="center">
<img src="./assets/presenting.png" width="720" alt="簡報" />
</p>

### 🎨 個性化定制

從內建主題和面板中選擇，或用自然語言描述一種風格，讓 AI 為你產生自訂面板。調整字型、間距和版面配置，打造你的專屬風格。

<p align="center">
<img src="./assets/theming.png" width="720" alt="個性化定制" />
</p>

### 📤 隨處匯出

一鍵匯出為 PDF、HTML、Word、PNG、EPUB 或心智圖。直接發佈到圖床服務。

<p align="center">
<img src="./assets/export.png" width="720" alt="隨處匯出" />
</p>

## 常見問題

<details>
<summary><strong>Calami 和 Typora / Obsidian / Bear 有什麼不同？</strong></summary>

Calami 將閱讀視為一等體驗 — 沉浸模式、即時翻譯、生字簿、仿生閱讀、文字轉語音全部內建。

</details>

<details>
<summary><strong>能離線使用嗎？</strong></summary>

可以。除了雲端 AI，所有功能都可離線使用。如果你使用 Ollama 等本地模型，AI 也能在無網路時運作。

</details>

<details>
<summary><strong>我的資料安全嗎？</strong></summary>

你的檔案以標準 Markdown 格式儲存在本機。無雲端同步，無需註冊帳號。AI 請求直接傳送到你選擇的服務商 — Calami 永遠不會看到你的內容。

</details>
