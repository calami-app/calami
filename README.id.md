## Mengapa Calami?

Sebagian besar aplikasi Markdown berfokus pada penulisan. Calami dibuat untuk **membaca dan menulis** — satu aplikasi di mana Anda bisa menulis artikel, mempelajari dokumen, menganotasi PDF, dan mempresentasikan slide, semuanya tanpa meninggalkan ruang kerja Anda.

Ringan, lintas platform, dan file Anda tidak pernah meninggalkan perangkat Anda.

## Fitur Utama

### 📖 Membaca Imersif

Ubah file Markdown apa pun menjadi pengalaman membaca yang bersih seperti buku. Pilih kata untuk mendapatkan terjemahan instan, sorot bagian dengan anotasi berkode warna, atau biarkan aplikasi membacakan untuk Anda.

<p align="center">
<img src="./assets/reading.png" width="720" alt="Membaca Imersif" />
</p>

### ✍️ Menulis dengan AI

Beralih antara mode teks kaya dan mode sumber kapan saja. Asisten AI ada di sidebar — minta untuk merangkum, melanjutkan menulis, memperbaiki tulisan, atau menerjemahkan. Gunakan kunci API Anda sendiri (OpenAI, Claude, Gemini, atau model lokal semuanya berfungsi).

<p align="center">
<img src="./assets/writing.png" width="720" alt="Menulis dengan AI" />
</p>

### 🎬 Presentasi

Ubah file Markdown apa pun menjadi slideshow dengan satu klik. Presentasikan ide Anda langsung dari catatan — tidak perlu beralih ke PowerPoint atau Google Slides.

<p align="center">
<img src="./assets/presenting.png" width="720" alt="Presentasi" />
</p>

### 🎨 Jadikan Milik Anda

Pilih dari tema dan skin bawaan, atau deskripsikan gaya dalam bahasa biasa dan biarkan AI menghasilkan skin kustom untuk Anda. Sesuaikan font, spasi, dan tata letak sesuai selera.

<p align="center">
<img src="./assets/theming.png" width="720" alt="Kustomisasi" />
</p>

### 📤 Ekspor ke Mana Saja

Satu klik untuk mengekspor sebagai PDF, HTML, Word, PNG, EPUB, atau peta pikiran. Publikasikan langsung ke layanan hosting gambar.

## FAQ

<details>
<summary><strong>Apa bedanya Calami dengan Typora / Obsidian / Bear?</strong></summary>

Calami memperlakukan membaca sebagai pengalaman kelas satu — mode imersif, terjemahan instan, buku kosakata, membaca bionik, dan text-to-speech semuanya sudah terintegrasi.

</details>

<details>
<summary><strong>Apakah bisa digunakan offline?</strong></summary>

Ya. Semua kecuali AI berbasis cloud berfungsi offline. Jika Anda menggunakan model lokal seperti Ollama, bahkan AI berfungsi tanpa internet.

</details>

<details>
<summary><strong>Apakah data saya privat?</strong></summary>

File Anda ada di perangkat Anda sebagai Markdown standar. Tanpa sinkronisasi cloud, tanpa akun yang diperlukan. Permintaan AI langsung ke penyedia yang Anda pilih — Calami tidak pernah melihat konten Anda.

</details>
